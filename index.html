🔧 How It Works

Open DevTools (F12) to see Dexie in action!

📦 1. Dexie Database

Two tables are created:

  • tasks Stores your to-do items
  • outbox Tracks pending sync changes
db.tasks → { id, title, completed }
db.outbox → { id, action, payload }

🔄 2. Sync Flow

  • 1 Add/Edit/Delete → saved to tasks
  • 2 Change recorded in outbox
  • 3 When online → sends to API
  • 4 Success → removes from outbox

🌐 3. Public API

Uses jsonplaceholder.typicode.com

  • POST /todos → CREATE
  • PUT /todos/1 → UPDATE
  • DELETE /todos/1 → DELETE

🔍 DevTools Steps

  • 1. Open Console F12 → Console
  • 2. View Database db.tasks.toArray()
  • 3. Check Outbox db.outbox.toArray()
  • 4. Manual Sync triggerSync()
  • 5. Application Tab → IndexedDB → see tables

📊 Status Indicators

  • 🟢 Online → sync ready
  • 🔴 Offline → changes queued
  • ⏳ Syncing → sending to API
  • ⏳ Pending → waiting to sync

💡 Try: Add a task, go offline (toggle network), add more, then go online to see sync!
